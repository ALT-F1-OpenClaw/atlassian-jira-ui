## Session 1 (17:30–18:00) — Docker DNS After Reboot

### Issue
After rebooting the Raspberry Pi, all Docker containers lost DNS resolution. OAuth login and Jira API calls failed with `[Errno -3] Temporary failure in name resolution`.

### Root Cause
Tailscale overrides `/etc/resolv.conf` with `nameserver 100.100.100.100`. Docker's internal resolver (`127.0.0.11`) couldn't reach Tailscale's DNS from inside containers.

### Fix
- Added `dns: [1.1.1.1, 8.8.8.8]` to both backend services in `docker-compose.yml`
- Documented in KNOWN_LIMITATIONS.md
- Recommended global fix: `/etc/docker/daemon.json` with DNS config
